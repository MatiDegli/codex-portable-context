# Documentation Guide

This repo keeps product and implementation documentation here, grouped by purpose.

## Canonical

- `architecture/`
  - architecture, mirror contract, security, transport, implementation conventions
- `continuity/`
  - handoff bundles, continuity guardrails, continuity bundle, Linux-to-Linux and Linux-to-Windows continuity guides
- `integrations/`
  - VS Code integration docs, CLI integration contracts, MCP bridge design, and MCP repo-boundary notes
- `providers/`
  - multi-provider strategy, provider guardrails, active provider briefs
- `validation/`
  - platform-specific validation guides and records

## Historical

- `history/`
  - migration-era docs, parity snapshots, old release drafts, blocked provider research

## Temporary Transition Notes

- `handoffs/`
  - short-lived migration and transition notes that are still useful during repo handoff or cleanup
